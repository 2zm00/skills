# 판정 규칙 R0~R13

예시블로그A IA·블로그(2026-10-06~10-16), 예시컴퍼니 IA(10-19), 예시피부과 제안(10-19~10-21)에서 실제로 쓰고 사용자가 확정한 규칙이다. 예시는 실측값.

## R0 검색량 하한 (포커스 키워드)

- 블로그 글 포커스는 네이버·구글 중 큰 값이 월 200 이상(가능하면 300 이상). 200 미만이면 상위 키워드로 넓히거나 다른 글과 합친다.
- 허브·서비스 페이지의 슬롯 키워드는 하한을 그대로 쓰지 않는다. 로컬·브랜드 키워드는 작아도 전환 의도가 강하면 쓴다(예: 강남 소프웨이브 네이버 50). 대신 "작다"고 표에 적는다.

## R1 검색량은 측정값 그대로

- 네이버(PC+모바일 합계)와 구글(정확 일치 행)을 둘 다 적는다. "0"은 10 미만으로 적는다.
- 도구가 지원하지 않는 시장(대만·영어권)은 비워 두고 "도구 미지원"으로 적는다. 서치콘솔 노출수로 대리 판단할 때는 그렇게 밝힌다.

## R2 정확 일치 0이어도 SERP로 의도 확인

- 상위에 같은 주제 페이지가 여럿이면 의도는 있다. 실제 유입은 구성 단어(헤드) 쪽에서 온다.
- 예: リニアジ 韓国 구글 일본 0인데 SERP 3위가 예시피부과 일본어 시술 페이지 → 유지.

## R3 의도 분류 (상위 8개 기준, `scripts/keyword/serp-intent.mjs`)

| 상위 구성 | 의도 | 노릴 수 있는 페이지 |
|---|---|---|
| 같은 업종 업체 사이트 5개 이상 | 업체 직접 경쟁 | 서비스·시술 페이지 제목으로 진입 가능 |
| 비교 플랫폼(강남언니·모두닥·크리에이트립·코네스트) 4개 이상 | 비교·추천 탐색 | 제목만으로 약함. 플랫폼 등재·비교형 콘텐츠 |
| 커뮤니티·SNS(Threads·Dcard·reddit·인스타) 비중 큼 | 경험·후기 | 홈페이지 제목보다 콘텐츠·채널 확산 |
| 공공기관·위키 | 목록·정의 | 헤드는 어렵다. 롱테일·데이터 콘텐츠 |
| 브랜드 사이트 1위 | 이동 | 브랜드 페이지만 해당 |

- 이동·목록 의도 키워드는 블로그 포커스로 잡지 않는다.
- 2026-10 측정: 한국어 로컬 의료 키워드(강남 울쎄라 등)는 구글 상위 8개 중 병원이 6~8개(직접 경쟁). 대만 키워드는 커뮤니티 비중이 커서 제목만으로 한계.

## R4 네이버 3천 규칙

- 네이버 월 3,000 이하이고 웹사이트 블록·웹문서 탭에 민간 사이트가 들어와 있으면 제목 슬롯으로 노린다. 메타타이틀만으로 진입 가능하다는 것이 사용자 규칙이다.
- 3,000 초과 헤드는 제목에 넣어도 본문(허브 표·상시 안내·비교 표)으로 겨룬다.
- 웹사이트 블록이 없고 광고·플레이스·클립만 있으면(예: 강남 피부과·강남 울쎄라, 2026-10-20) "홈페이지 제목은 레버가 아님, 플레이스·블로그 영역"이라고 적는다.
- 네이버 첫 화면에 우리 도메인이 보이면 반드시 광고인지 자연 노출인지 구분한다(예: 강남 리프팅에서 example-clinic은 파워링크 광고).

## R5 토큰 매칭

- 긴 키워드가 짧은 키워드의 단어를 다 품으면 둘 다 받는다(대학생 공모전 사이트 → 공모전 사이트, AI경진대회 → AI대회). 이미 덮인 조합을 따로 넣지 않는다.

## R6 겹침·잠식 검사

- 같은 사이트의 다른 페이지 제목, 블로그 글, 다른 언어 페이지와 같은 키워드를 겨냥하면 하나만 남긴다.
- 같은 글이 주소 두 개로 노출되면(예: /tw/allergan-vs-xeomin_tw/ 111클릭 vs /tw/allergan-vs-xeomin/ 15클릭) 제목보다 주소 통합이 먼저다.

## R7 수식어는 페이지가 다룰 때만

- 상위 제목에서 반복되는 수식어(가격·잘하는곳·추천·후기·料金·おすすめ·price)를 찾는다.
- 페이지에 실제 가격·사례가 있을 때만 넣는다. 없으면 본문을 보강하거나 뺀다.

## R8 형식

- 포커스 키워드를 맨 앞에. 브랜드는 끝에 `| 브랜드`.
- 한국어 허브는 `키워드 · 키워드 · 키워드 | 브랜드`(예시블로그A·예시컴퍼니 확정 형식).
- 폭: `scripts/keyword/title-px.mjs`로 측정해 561px 이하(스크리밍프로그 경고선). 한글 약 16.6px, 한자·가나 16.9px, 영문 소문자 9.4px, 대문자 11.8px, 공백 5.2px.
- 검색량 0 단어는 제목에서 빼고 H1·설명에 둔다.

## R9 근거 남기기

- "전에는 ~ 때문에, 지금은 ~ 이유로"로 적는다. 바꾼 경우 이전 제목을 `prev_title`로 남긴다.

## R10 로컬 업체 공식

- 지역+서비스를 맨 앞에 붙여 쓴다: `강남울쎄라 | 강남역 울쎄라 프라임 | 예시피부과의원 강남점`.
- 근거: 경쟁의원A `은평위고비 | 연신내역위고비 | 경쟁의원A 은평점`, 경쟁의원B `강남울쎄라 잘하는곳 - 강남역 울쎄라 잘하는곳 경쟁의원B`이 2026-10 SERP 1~4위.
- 같은 형식의 지역 페이지를 지역명만 바꿔 대량 생산하지 않는다(구글 도어웨이 정책). 실제 지점이 있는 지역만.

## R11 해외 시장은 현지 검색어로

- 번역하지 않는다. 현지 SERP 상위 제목의 표현을 쓴다.
- 일본: リフトアップ(リフティング 아님), 美容皮膚科, 江南은 아이치현 江南市와 겹치므로 江南(カンナム) 또는 韓国 江南. 料金·おすすめ 수식어.
- 대만: 醫美, 韓國江南醫美, 療程價格. 간체(简体)와 섞지 않는다.
- 영어: 정식 장비명(Sofwave, Shurink, Ultherapy), "in Gangnam, Seoul", Price & Treatment.
- 원장이 말한 목표 시장 외 언어는 제목 작업 우선순위에서 뺀다.

## R12 옛 브랜드 잇기

- 리브랜딩 후에도 옛 이름 검색이 남아 있으면 제목·본문에 병기한다: 旧エグザンプル江南, 舊Example Old江南店, (구 예시옛브랜드).
- 옛 이름을 다른 지점이 계속 쓰면(예시옛브랜드 명동점) 지역명까지 붙여 구분한다.
- 1~2년 뒤 옛 이름 검색량을 다시 재서 줄인다.

## R13 업종 규제

- 의료: 'No.1·최고·유일' 같은 최상급 표현 금지(의료법 제56조 과장 광고 위험). 경쟁사가 써도 따라 하지 않는다.
- 가격을 제목·설명에 넣으려면 페이지에 금액·조건이 함께 있어야 한다.
- 판단이 애매하면 표현만 표시하고 심의·법률 검토가 필요하다고 적는다.
