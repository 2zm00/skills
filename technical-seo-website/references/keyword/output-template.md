# 보고 형식

## 1. 페이지별 메타타이틀 표

| 페이지 (역할) | 현재 타이틀 | 제안 타이틀 (폭) | 슬롯 키워드: 네이버 / 구글 | SERP 판정 (구글 · 네이버) | 서치콘솔 현재 | 근거 |
|---|---|---|---|---|---|---|
| /ja/ (일본어 홈) | EXAMPLE 医院 江南店｜リフティング・アンチエイジング | 韓国美容皮膚科 江南(カンナム) EXAMPLE｜旧エグザンプル江南 (493px) | 韓国 美容皮膚科 - / 390, エグザンプル 江南 - / 720 | 업체 경쟁, 현재 1위(브랜드) · 미조회 | エグザンプル 江南 1.8위, 318클릭 | 전에는 リフティング(일본 표현 아님)·美容皮膚科 없음 때문에 일반 검색에 안 걸렸고, 지금은 현지 표현과 옛 이름 병기로 1위 유지+일반 검색 진입 |

- 폭은 `scripts/keyword/title-px.mjs` 값. 561px 넘으면 줄인다.
- 검색량 칸: 측정 안 한 쪽은 `-`, 도구 미지원은 "미지원", 10 미만은 "<10".
- 서치콘솔 순위는 노출 가중 평균(띄어쓰기·붙여쓰기 변형 합산)이라고 밝힌다.

## 2. 시장별 요약 (3~5줄씩)

- 이길 수 있는 키워드: 근거(의도·경쟁 구성·검색량).
- 콘텐츠로 넘길 키워드: 페이지가 다루지 않거나 플랫폼·커뮤니티 의도.
- 제외 키워드와 이유: 의도 불일치, 공공·위키 독점, 규제, 클라이언트 범위 밖.

## 3. 측정 한계

- 조회한 날짜, 국내 IP 한계, 조회 못 한 시장·엔진, 도구 미지원 검색량, 서치콘솔 기간.

## 4. 저장할 것

- `tmp/naver_vol.json`, `tmp/google_vol.json`, `tmp/serp_google.json`, `tmp/serp_naver.json`, `tmp/gsc_queries.json`.
- 확정되면 페이지별 `{page, prev_title, title, keywords:{kw:{naver, google}}, serp_verdict, reason}`을 클라이언트 프로젝트 기록에 남긴다.
