# 런칭 등록과 운영

예시컴퍼니는 GA만 붙이고 서치콘솔 등록을 미뤘다. 그래서 오픈(10/22) 뒤 5일 동안 구글·네이버·빙 어디에도 색인되지 않았다. 런칭 당일 아래를 한 번에 끝낸다.

## 0. 킥오프 때 정할 것

**계정**
- 서치콘솔·GA를 소유할 구글 계정과 서치어드바이저용 네이버 계정을 정한다.
- 고객 사이트는 고객 명의로 만들고 우리를 사용자로 추가하는 방식을 권한다.
- 예시컴퍼니는 대표의 구글 계정과 네이버 계정 하나씩으로 서치콘솔·GA·서치어드바이저·빙을 모두 묶었다.

**소유 확인 방법**

| 방법 | 조건 | 비고 |
|---|---|---|
| DNS TXT (도메인 속성) | DNS(Cloudflare 등) 관리 권한 | 하위 도메인까지 한 번에 확인. 배포가 필요 없다 |
| 메타 태그 + HTML 파일 (URL 접두어 속성) | 코드 배포 | 예시컴퍼니 방식. 둘 다 넣어 한쪽이 빠져도 유지된다 |
| GA 태그 | GA가 `<head>`에 바로 있어야 함 | GA를 `lazyOnload`로 늦게 불러오면 실패한다 |

**코드에 미리 둘 자리**
- `companyInfo`: `googleSiteVerification`, `naverSiteVerification`, `indexNowKey`, `gaMeasurementId`
- `public/`: 확인 파일과 IndexNow 키 파일
- 런칭 전에 서치콘솔·서치어드바이저 속성부터 만들어 값을 받으면 첫 배포에 같이 넣을 수 있다.

## 1. 구글 서치콘솔

1. 웹사이트 추가 → URL 접두어 `https://<도메인>/`.
2. 소유 확인 화면에서 HTML 파일 이름과 HTML 태그 `content` 값을 받는다. 코드에 넣고 배포한 뒤 "소유권 확인"을 누른다.
3. Sitemaps에 홈페이지 `sitemap.xml`, `blog/sitemap_index.xml`을 제출한다. 블로그 인덱스가 처음에 "가져올 수 없음"이면 `blog/post-sitemap.xml`도 따로 낸다(구글봇으로 받아 200인지 먼저 확인).
4. URL 검사 → "색인 생성 요청". 하루 10~12개에서 "할당량 초과"가 뜬다.
   - 요청 순서: 홈 → 핵심 서비스 → 업종 → 블로그 글 → 대표 사례.
   - 나머지는 사이트맵이 가져간다.
5. 사용자 추가: 설정 → 사용자 및 권한 → 사용자 추가 → 권한 "전체". 소유자는 한 명만 둔다.

## 2. GA4

- 속성은 시간대 한국, 통화 원, 데이터 보관 14개월로 만든다. 블로그(워드프레스)도 같은 측정 ID를 쓰고, Site Kit은 연결하지 않는다(태그 중복).
- 서치콘솔 연결 순서:
  1. 관리 → 제품 링크 → Search Console 링크 → 연결
  2. "계정 선택" → 사이트 행 체크 → 확인 → 다음
  3. 웹 스트림 선택 → 다음 → 제출
- 사용자 추가 순서:
  1. 관리 → 속성 액세스 관리 → + → 사용자 추가
  2. 이메일 여러 개 입력(Enter로 구분)
  3. 역할은 편집자. 다른 사용자까지 관리해야 하면 관리자.
- 주요 이벤트(키 이벤트):
  1. 문의 접수 완료, 카카오톡 클릭, 전화 클릭에 코드로 `gtag('event', ...)`를 넣는다.
  2. GA 관리 → 이벤트에서 주요 이벤트로 표시한다.
  3. CTA 문구·위치가 확정된 뒤에 붙인다.

## 3. 네이버 서치어드바이저

1. 로그인한다. 처음 쓰는 계정은 이용약관 동의가 뜬다.
2. 사이트 등록에 `https://<도메인>`을 넣는다.
3. 소유 확인은 HTML 파일(권장)과 HTML 태그 값을 둘 다 코드에 넣고, 배포 후 "소유확인"을 누른다. 보안 문자(이미지 글자)를 입력한다.
4. 요청 → 사이트맵 제출: 홈페이지와 블로그 사이트맵을 각각 전체 주소로 넣는다.
5. 요청 → RSS 제출: 블로그가 있으면 블로그 피드 `https://<도메인>/blog/feed/`, 없으면 홈페이지 피드 `https://<도메인>/rss.xml`. 보안 문자가 뜬다.
6. 요청 → 웹 페이지 수집: 주요 주소를 하나씩 넣는다. 예시컴퍼니는 13개를 넣었다.

## 4. 빙 웹마스터

1. Sign In → Google을 고르고 서치콘솔 계정을 선택한 뒤 계속한다.
2. "Import your sites from GSC" → Continue → 계정을 다시 선택하고 권한을 계속한다.
3. 사이트 목록에서 **이 사이트만 남기고** Import한다. 같은 계정의 다른 고객 사이트가 기본으로 체크돼 있다.
4. 사이트맵은 자동으로 같이 들어온다. 소유 확인은 따로 필요 없다.

## 5. IndexNow

- 키는 32자 hex다. `public/<키>.txt` 파일에 키만 넣는다.
- `node scripts/indexnow-submit.mjs --host <도메인> --key <키>`를 실행하면 api.indexnow.org, bing.com, searchadvisor.naver.com에 사이트맵 주소 전체가 제출된다. 202·200이면 정상이다.
- 큰 변경을 배포한 뒤에도 다시 실행한다.
- 워드프레스 블로그는 Rank Math의 IndexNow를 쓴다(키 별도).

## 6. 배포 후 확인

- 배포 직후 `node scripts/launch-check.mjs https://<도메인> --files <구글 확인 파일>,<네이버 확인 파일> --indexnow-key <키> --ga G-… --blog /blog/`를 돌린다. 지운 주소가 있으면 `--removed "/old>/new"`를 더한다. 실패 0개가 목표다.
  - 예시컴퍼니 2026-10-29 실사이트 결과: 실패 0 / 확인 23 / 참고 2. `/google-business-profile` → `/marketing-mix` 308, 사이트맵 19개.
- 메타는 `node scripts/meta-audit.mjs https://<도메인> --brand <브랜드>`로 본다. 예시컴퍼니 2026-10-29: 19쪽, 높음·중간 0건, 낮음 6건(사례 페이지 제목의 부분 겹침, 의도한 것).
- 3~4일 뒤:
  - 구글·네이버 `site:<도메인>` 검색
  - 서치콘솔 페이지 색인 보고서와 사이트맵 상태
  - GA 획득 채널에 Organic Search가 잡히기 시작했는지
- 2주 뒤: 서치콘솔 검색어·평균 순위를 IA 문서의 목표 키워드와 비교해 보고한다.

## 7. 페이지 삭제·주소 변경

1. `next.config.ts`에 301(`permanent: true`)을 걸고 `pageMeta`에서 지운다. 사이트맵에서 빠졌는지 확인한다.
2. 내부 링크, 관련 링크 맵, 문의 폼 선택지, 구조화 데이터, IA 문서를 정리한다.
3. 배포 후 서치콘솔에서 새 주소를 색인 요청하고 IndexNow로 알린다.
4. 서치콘솔 "삭제" 도구는 쓰지 않는다. 임시 숨김일 뿐이고 301이 맞다.

## 8. 배포 (팀 저장소)

- 새 브랜치 + PR만 올린다. 머지는 저장소 주인이 한다. Vercel은 팀 멤버가 머지한 커밋만 배포하고, 멤버가 아닌 계정이 머지하면 "Deployment was blocked"가 뜬다.
- 주인이 머지했다고 하면 실사이트를 curl로 확인한 뒤 다음 단계로 간다. 확인할 것: 확인 파일 200, 메타 태그, 바뀐 제목.

## 9. Aside 브라우저 요령 (2026-10-27 실사용)

**서치콘솔**
- 속성 화면은 `https://search.google.com/search-console?resource_id=<encodeURIComponent('https://도메인/')>`로 바로 연다.
- 소유권 확인 대화상자의 HTML 태그 값은 `document.querySelectorAll('input,textarea,code,pre')`에서 `google-site-verification`이 든 값을 읽는다.
- URL 검사는 상단 "검사" 입력칸에 주소를 넣고 Enter를 친다. `?id=` 직접 주소는 404다.
- 결과 화면 버튼 이름은 "색인 생성 요청다시 요청"처럼 붙어 나온다. `/button "색인 생성 요청[^"]*"/`로 찾는다.
- 응답 문구는 "색인 생성 요청됨" 또는 "할당량 초과"다. 요청 하나에 1~2분 걸린다.

**GA4**
- Search Console 링크의 계정 선택 패널에서 체크박스는 `[hidden]`이다. 행의 label을 클릭한다.

**네이버**
- Aside 비밀번호 관리자에서 계정 항목을 찾아 자동 입력한다. 영수증 보안 질문이 나오면 답한 뒤 "다시 로그인해 주세요"가 뜬다. 자동 입력을 한 번 더 하면 넘어간다.
- 보안 문자는 대화상자의 `background-image`에 있는 `captcha.nid.naver.com/nhncaptchav4.gif?key=…` 주소를 받아 이미지로 보고 입력한다. 안 읽히면 "새로고침"을 누른다.
- 사이트맵·RSS·수집 입력칸은 `fill`로 넣은 값이 제출되지 않을 때가 있다. 클릭 → 전체 선택 → 지우기 → 한 글자씩 입력(`type`) → 확인 순서로 넣는다. 사이트맵은 경로만 넣으면 안 되고 전체 주소로 넣는다.

**빙**
- Sign In 대화상자의 Google 버튼은 접근성 트리에 안 보인다. 화면 캡처로 위치를 보고 클릭한다.
- 가져오기 사이트 목록도 체크박스를 좌표로 해제한다.
