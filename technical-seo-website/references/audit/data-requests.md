# 사람에게 받을 자료 (B 항목·A+ 권한)

클라이언트는 개발자가 아닐 수 있다. 요청은 "무엇을, 어디서, 어떻게" 세 줄로 쓰고, 화면 캡처 예시를 같이 보낸다.

## 1. 권한 (받으면 에이전트가 직접 확인: A+)

| 무엇 | 왜 | 어떻게 (클라이언트용) |
|---|---|---|
| 서치콘솔 **소유자** 또는 전체 권한 | 색인·크롤 통계·URL 검사·주소 변경 도구 | 서치콘솔 → 설정 → 사용자 및 권한 → 사용자 추가 → 이메일 입력 → 권한 "전체"(주소 변경까지 하려면 소유자) |
| 옛 도메인 서치콘솔 | 과거 실적·주소 변경 신청 | 옛 사이트 속성에서 같은 방식으로 추가. 옛 속성이 없으면 새로 등록해야 함 |
| GA4 뷰어 | 전환·채널 확인 | GA4 → 관리 → 속성 액세스 관리 → + → 뷰어 |
| 구글 비즈니스 프로필 관리자 | 인사이트·설정 | 프로필 → 메뉴 → 비즈니스 프로필 설정 → 사용자 → 추가 → 관리자 |
| 네이버 서치어드바이저 | 국내 수집 현황(국내 타깃일 때) | 서치어드바이저 → 사이트 관리 → 소유자 추가(또는 화면 캡처) |

## 2. 사람이 측정·제공해야 하는 것 (B)

| 항목 | 받을 것 | 요청 문구 예 |
|---|---|---|
| 전체 사이트 크롤 (T22) | 스크리밍프로그 유료판 전체 크롤 내보내기: Internal All, Response Codes, Canonicals, Hreflang, Structured Data | "스크리밍프로그로 전체를 크롤한 뒤 Bulk Export에서 위 5개를 CSV로 보내 주세요" |
| 서버 로그 (T21) | 최근 30~90일 접근 로그(호스팅·Cloudflare) | "호스팅 관리 화면에서 웹 접근 로그를 내려받을 수 있는지 확인해 주세요" |
| 방화벽·CDN 설정 (T17 원인) | Cloudflare 보안 → Bots·WAF 이벤트 화면, 국가 차단 규칙 | "Cloudflare 보안 메뉴의 Bots 화면과 최근 차단 이벤트 화면을 캡처해 주세요" |
| 개발 방식 확인 (T13, T37 의도) | 사이트맵 생성 방식, 302·307을 쓴 이유, 템플릿 구조 | 질문지: ① 새 글 올리면 사이트맵이 자동 갱신되나요 ② 리디렉션을 임시(302)로 둔 이유가 있나요 |
| 전환 완료 페이지 (T100) | 테스트 예약 1건으로 완료 페이지 URL, 회원 영역 경로 | "테스트 예약을 한 번 해서 완료 화면 주소를 알려 주세요" |
| 실기기 모바일 (T69·T83) | 아이폰·갤럭시 첫 화면 캡처(홈·시술 상세) | "휴대폰으로 두 페이지를 열어 첫 화면을 캡처해 주세요" |
| 정확한 미사용 CSS (T80) | 크롬 개발자도구 Coverage 캡처(페이지 3곳) | 개발자에게 요청 |
| 해외 실제 화면 (T18·T102) | VPN으로 대상 국가 접속 화면, 그 나라 검색 결과 | "일본·대만 VPN으로 홈과 '韓国 美容皮膚科' 검색 결과를 캡처해 주세요" |
| 콘텐츠 제작 방식 (T99) | 글 작성 주체, AI 사용 여부, 의료진 검수 여부 | 인터뷰 질문 |
| 자격 증빙 (T89) | 의료진 전문의 자격·학회 정보 원본 | 병원에 요청 |
| 키워드 검색량 (대만·영어권) | 구글 키워드 플래너 내보내기 | 구글 광고 계정 보유 시 요청 |
| 과거 실적 (T39) | 옛 서치콘솔 실적 화면(16개월) | 클라이언트가 말한 수치는 이 화면으로 확인 전까지 사실로 쓰지 않는다 |

## 3. 요청 메시지 틀

```
안녕하세요, 진단을 정확히 하려고 아래 자료를 부탁드려요.
1) [무엇] / [어디서] / [어떻게]  (캡처 예시 첨부)
2) ...
자료가 어려운 항목은 "확인 불가"로 표시하고 나머지로 진단을 진행합니다.
```

- 받지 못한 항목은 보고서에 "확인 불가(○○가 있으면 확인 가능)"으로 남긴다.
