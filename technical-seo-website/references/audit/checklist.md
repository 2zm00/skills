# 테크니컬 SEO 진단 항목 (마스터 체크리스트)

예시성형외과 체크리스트 89개 + 예시성형외과 리포트 69개 항목 + 예시피부과 진단에서 새로 나온 항목을 합쳤다. 진단할 때는 범위(`tiers.md`)에 맞는 항목을 모두 판정한다. 데이터는 `checklist.json`(같은 내용)에서 스크립트가 읽는다.

## 구분 기호

- **A 단독**: 공개 접근만으로 에이전트가 끝까지 확인한다.
- **A+ 권한 필요**: 서치콘솔·GA4·비즈니스 프로필·서치어드바이저 읽기 권한을 받으면 에이전트가 직접 확인한다. 권한이 없으면 "사람이 줄 것" 칸의 화면·CSV를 받는다.
- **B 사람 측정 필요**: 사람이 측정하거나 자료를 줘야 판정할 수 있다. 받은 뒤 분석은 에이전트가 한다.
- **C 확정 불가**: 사람이 측정해도 정답을 확정할 수 없다. "간접 조사" 칸의 방법으로 근거를 쌓고, 보고서에 추정임을 밝힌다.
- 한 항목 안에서도 일부만 B·C인 경우가 있다. "사람이 줄 것"과 "확정 못 하는 부분" 칸을 같이 본다.

범위: **공통·B2C핵심** = B2C 라이트 진단에서도 반드시 판정하는 26개 / **공통** = B2B와 B2C 스탠다드 필수, B2C 라이트에서는 스크립트로 훑고 문제가 나올 때만 기재 / **B2B** = B2B 필수(B2C는 선택) / **조건부** = 해당 사이트 유형일 때 필수(다국어·의료·커머스·리브랜딩 등) / **선택** = 시간이 될 때.

총 103개: A 83 · A+ 13 · B 4 · C 3 (일부 사람 자료가 필요한 항목 32개, 일부 확정 불가인 항목 16개). 범위: 공통 50(그중 B2C핵심 26) · B2B 18 · 조건부 14 · 선택 21.
