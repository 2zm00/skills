# 진단 범위: B2C 라이트 vs B2B 풀

예산·기대치가 다르다. B2C(병원·뷰티·로컬 업체)는 "손실을 멈추는 최소 정비"를 빠르게, B2B(기업·플랫폼·커머스·대형 다국어)는 "개발팀이 그대로 작업할 수 있는 수준"까지 간다.

| 구분 | B2C 라이트 | B2B 풀 (예시성형외과 리포트 수준) |
|---|---|---|
| 항목 | **B2C핵심 26개** + 해당 조건부 (`init --tier b2c --extra ...`). 나머지 공통 24개는 스크립트(site-probe·페이지 안 점검)로 훑기만 하고, 문제가 보일 때만 추가 | 103개 전부 (`init --tier b2b`) |
| 판정 깊이 | 템플릿 대표 페이지(홈·목록·상세·글·문의) 위주. 정상은 요약 표 한 줄 | 템플릿별·언어별 전수. 정상도 근거 카드 |
| 데이터 | 서치콘솔 권한 + 공개 실측(A·A+) | A·A+ 전부 + B 자료(전체 크롤, 서버 로그, CDN 설정, 개발자 답변) |
| 증거 | 문제·보완 항목만 캡처 1장 이상 | 전 항목 캡처, 수치 원자료(CSV·JSON) 첨부 |
| 산출물 | 리포트 20쪽 안팎(`cards: issues`, 문제·보완 카드 10~15개 기준), 조치 10개 우선순위, 바로 쓸 수 있는 목록(새 제목·리디렉션 표) | 리포트 100쪽 안팎(`cards: all`. 예시성형외과: 69개 항목 114쪽·캡처 94장), 개발 티켓 수준 조치 명세(파일·템플릿·기대 HTML), 이슈 시트, 수정 후 재검증 리포트 |
| 추가 | 로컬 SEO(구글 비즈니스 프로필·NAP·리뷰), 메타타이틀 10~20개(`references/keyword/strategy.md`) | 경쟁사 기술 벤치마크, 크롤 예산·로그 분석, 국제화 설계, 구조화 데이터 그래프 설계, 월간 모니터링 |
| 공수(참고) | 2~4일 | 2~3주 (예시성형외과: 2026-07-28 ~ 08-11) |
| 가격대(추정, 근거 약함) | 진단 100만~300만 원, 월 관리 50만~150만 원 | 진단 800만~2,000만 원, 월 관리 300만~500만 원 |

중간 단계가 필요하면 **B2C 스탠다드**(`init --tier std`, 공통 50개 + 조건부)를 쓴다. 예산은 B2C인데 사이트가 크거나(글 1,000개 이상) 다국어인 경우다.

B2C핵심 26개: T01 robots · T02 noindex · T05 색인 상태 · T06 등록 불가 원인 · T10 호스트 상태 · T11 사이트맵 · T17 봇 차단 · T18 해외 IP 차단 · T23 URL 중복 · T24 파라미터 중복 · T27 canonical · T37 301 상태 · T40 5XX·429 · T41 TTFB · T44 HTML 크기 · T45 공통 헤더·푸터 · T48 내부 링크 · T49 앵커텍스트 · T52 title · T63 JS 렌더링 · T69 모바일 · T74 코어 웹 바이탈 · T85 구조화 데이터 · T92 비즈니스 프로필·NAP · T94 트래픽 변동 · T95 패널티. (공통 중 중요도 '고' 22개 + 로컬 업체에 효과가 큰 4개)

## B2C라도 B2B 항목을 더해야 하는 경우

- 다국어 사이트(해외 환자 비중이 큼): T90 hreflang, T91 자동 리다이렉트, T18 해외 접속, T102 현지 순위 표본.
- 리브랜딩·도메인 이전 이력: T39 이전 연결 + 옛 도메인 매핑표.
- 글이 1,000개 이상이거나 월 수백 개 발행: T08 발견됨 적체, T99 대량 발행, T22 전체 크롤.
- JS 프레임워크(Next.js·SPA): T63 렌더링, T30 URL 개별화, T42 소프트 404.
- 서브도메인 여러 개: T16 개발 서버 노출, T35 사이트 분산.

## 공통 원칙

- 범위와 상관없이 판정 기준·문장 규칙(`report-style.md`)은 같다. 깊이와 분량만 다르다.
- B2C는 "고칠 수 있는 사람"이 병원 실무자·외주 웹 업체인 경우가 많다. 조치는 메뉴 위치 수준으로 쉽게 쓴다.
- 가격대는 공수로 거꾸로 계산한 추정이다. 시장 참고값은 2026-10 웹 검색에서 본 국내 SEO 대행 월 150만~500만 원, 일회성 500만~3,000만 원 수준 하나뿐이다(업체 1곳 자료). B2C 월 관리비는 이 범위보다 낮게 잡았다. 제안서에 넣기 전에 예시컴퍼니 단가 기준과 실제 견적 사례로 다시 맞춘다.
