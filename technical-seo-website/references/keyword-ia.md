# 키워드·IA·메타타이틀

예시컴퍼니 IA v2~v4(2026-10-19~27)에서 사용자가 확정한 방식이다. 측정 도구와 판정 규칙 전체는 `references/keyword/`(`strategy.md`, `rules.md` R0~R13)에 있고, 여기는 홈페이지 제작에 필요한 부분만 정리한다.

## 1. 페이지 역할부터 정한다

- 브랜드는 역량 중심으로 세우고 업종은 입구 페이지로 둔다. 한 업종 전문 회사로 묶이면 다른 업종(B2B 등)으로 넓히기 어렵다.
  - 메인: 회사 정체성 + "업체 찾기" 의도
  - 서비스 페이지: 서비스마다 하나
  - 업종 페이지: 병원·B2B 같은 수직 입구
  - 신뢰·전환: 사례 목록·상세, 회사소개, 문의
  - 블로그: 정보형 키워드
- 페이지가 실제로 다루는 서비스만 제목에 넣는다. 검색량이 커도 다루지 않으면 블로그 몫이다.
- 운영하지 않을 서비스는 "검색 입구용"으로라도 페이지를 만들지 않는다. 예시컴퍼니는 구글 비즈니스 프로필 페이지를 메뉴 밖에 뒀다가 결국 삭제하고 301로 넘겼다.

## 2. 후보를 만들고 잰다

- 페이지당 후보 10~25개를 만든다.
  - 서비스명, 서비스 + 업체·대행사·컨설팅·제작·비용
  - 업종 + 서비스, 지역 + 서비스
  - 동의어(GEO·AEO·AI 검색 최적화), 붙여쓰기·띄어쓰기 변형
- 검색량은 `scripts/keyword/volumes.mjs --naver "a,b" --kr "a,b" --out <폴더>`로 잰다.
  - 네이버는 마피아넷(PC+모바일 합계), 구글은 keyword-analyzer-topaz(한국, 정확 일치 행)다.
  - 네이버 0은 "10 미만"으로 적는다.
- 숫자 옆에 측정일을 적는다. 문서를 갱신할 때는 제목에 든 키워드를 같은 날 전부 다시 잰다. 날짜가 섞이면 비교가 안 된다.

**측정 도구가 없을 때** (마피아넷·topaz 응답 없음·차단)
- 후보 목록을 먼저 만들어 사용자에게 주고, 검색량 표를 받는다. 무료 출처: 네이버 검색광고 키워드 도구(searchad.naver.com, 광고주 가입 필요, PC+모바일 합산), 구글 키워드 플래너(Google Ads 계정 필요, 한국·한국어 설정).
- 받은 숫자는 출처와 측정일을 같이 적는다(IA 문서 머리의 "도구" 칸). 키워드 플래너의 범위값(예: 1천~1만)은 범위 그대로 적는다.
- 표를 받지 못하면 검색량 칸을 "미측정"으로 두고 SERP만으로 판정한 초안이라고 IA 문서 머리에 적는다. 3,000 기준 판정(§3 표)은 하지 않고, 사용자 확인 때 측정을 다시 요청한다.
- 검색량도 SERP도 없으면(Aside 없음 + 캡처 없음) 제목은 서비스명 기준 가안으로만 만들고, IA 문서 머리에 "근거 없음 가안"이라고 적는다. 개발 전에 사용자에게 이 상태로 갈지 묻는다.
- 어떤 경우에도 검색량을 추정해서 적지 않는다.

## 3. SERP를 네이버·구글 둘 다 본다

**네이버 통합검색**
- 블록 순서(광고·플레이스·AI 브리핑·웹사이트·클립·브랜드 콘텐츠)를 본다.
- 웹사이트 블록이 있는지, 그 안에 민간 사이트(업체·대행사)가 몇 번째에 있는지 본다.
- 웹문서 탭(`&ssc=tab.web.all`) 상위 도메인도 본다.

**구글**
- 상위 10개 도메인을 유형별로 나눈다: 업체·대행사 / 플랫폼 / 위키·공공 / 언론·교육 / 커뮤니티.
- AI 개요가 있는지 본다.
- 한국 결과는 한국 IP의 실제 브라우저로 본다. topaz `/api/serp`는 미국 쪽으로 치우쳐 한국 순위 근거로 쓰지 않는다.
- 자동 검색은 30초에 6회 안팎에서 캡차가 뜬다. 나눠서 본다.

**판정**

| 상황 | 판단 | 예시컴퍼니 예 (10/27) |
|---|---|---|
| 네이버 3,000 이하 + 웹사이트 블록·웹문서 상위에 민간 사이트 | 제목 슬롯. 제목만으로 진입 가능 | IMC마케팅 N840/G720, GEO업체 N310/G480 |
| 3,000 초과지만 웹사이트 블록에 업체가 들어옴 | 제목에 넣고 "3천↑ 본문 보강"으로 표시 | 병원마케팅 N6,150, 메타광고 N5,980 |
| 웹사이트 블록 없음, 블로그·위키·언론·교육기관만 | 제목에서 뺀다 | 디지털마케팅 N350, 브랜드마케팅 N680, 마케팅대행사 N990 |
| 동음이의·다른 의도 | 뺀다 | AEO(관세청 인증), CRO(임상시험), 마케팅믹스(4P 학습), 브랜드명(같은 이름의 영화) |
| 공공·플랫폼 독점 | 뺀다 | 마케팅교육(소진공·KPC) |
| 아주 작지만 웹사이트 블록에 업체가 보임 | 보조 슬롯 가능, "소량" 표시 | 통합마케팅 N40/G30 |
| 검색량 목적이 아닌 페이지 | 브랜드·전환 문구만 | 회사소개, 문의, 블로그 메인 |

## 4. 메타타이틀 공식

- 형식은 `포커스 · 키워드2 · 키워드3 | 브랜드`이고 포커스를 맨 앞에 둔다.
- 3슬롯 중 적어도 하나는 3,000 이하 진입 가능 슬롯으로 채운다.
- 폭은 561px 이하다(`scripts/meta-audit.mjs`가 잰다). 예시컴퍼니 제목은 363~524px이다.
- 한 키워드는 한 페이지만 맡는다.
  - 메인이 "마케팅컨설팅"을 가지면 다른 페이지 제목에 쓰지 않는다.
  - GEO마케팅은 /geo에만 쓴다.
  - 긴 키워드가 짧은 키워드를 품으면 짧은 것은 따로 넣지 않는다.
- 전문성: 채널·도구 이름보다 전략 용어를 쓴다.
  - 2026-10-27 사용자 결정: /marketing-mix를 "그로스마케팅 · 인플루언서마케팅 · 네이버플레이스마케팅"에서 "그로스마케팅 · IMC마케팅 · 통합마케팅"으로 바꿨다.
  - 이유: 채널 이름은 컨설팅 회사를 단품 대행사처럼 보이게 한다.
- 서술형·후킹 문구는 쓰지 않는다: "~하는 법", "총정리", "완벽 가이드", "No.1". 의료는 최상급 표현을 금지한다.
- 검색량 0인 단어는 제목에서 빼고 H1·설명에 둔다.
- 브랜드가 다른 것과 겹치면 브랜드 페이지에서 구분한다: 회사소개 `회사소개 · 팀 | 예시컴퍼니 마케팅`, 구조화 데이터 `alternateName`.

**H1과 메타 설명**
- H1은 사람이 읽는 서비스 이름이다. 단답형으로 쓴다(예: "테크니컬 SEO 웹사이트 개발"). 바로 아래 한 줄 설명을 붙인다.
- 제목은 키워드 묶음이라 H1과 같을 필요가 없다.
- 메타 설명은 검색한 사람이 얻는 것과 근거 한 가지를 1~2문장(한글 80~150자)으로 쓴다. 제목 키워드를 자연스럽게 1~2개 넣는다.

## 5. IA 문서 형식

위치는 `docs/<브랜드>_IA_메타타이틀_vN.md`이다. 버전마다 새 파일을 만들고 이전 버전을 남긴다.

1. **머리**: 기준(설계안·실사이트), 측정일, 도구, "vN-1 대비 바뀐 점"
2. **메뉴 구조**: 헤더 그룹, 메뉴 밖 페이지, 리디렉션
3. **페이지 표**: 경로 | 화면 제목(H1) | 메타타이틀 | 근거(키워드별 N/G, 3천↑ 표시, SERP 메모)
4. **상세 표**: 사례·글
5. **변경 기록**: 이전 → 변경, 이유, 측정값
6. **제외 키워드와 이유**, 2차 후보 페이지
7. **운영 규칙**: 키워드 겹침 금지, 3천 규칙, 30% 규칙

한눈에 보는 PNG가 필요하면 표를 HTML로 그려 PNG로 저장한다. 예시컴퍼니 v4는 `<프로젝트>/docs/예시컴퍼니_IA_메타타이틀_v4.png`.
