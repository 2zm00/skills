## Installation

레포지토리를 클론합니다.

   ```bash
   git clone https://github.com/2zm00/skills.git
   cd skills
   ```

원하는 스킬 폴더를 Claude Code 스킬 경로에 복사(또는 심볼릭 링크)합니다.

   ```bash
   cp -R technical-seo-website ~/.claude/skills/
   ```
